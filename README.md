# 🖥 PC Builder — Telegram-бот для подбора ПК

Бот собирает компьютер из каталога комплектующих под бюджет и задачи, проверяет совместимость,
считает варианты апгрейда, показывает реальные замеры FPS и сравнивает цены магазинов.

**Главный принцип проекта: бот ничего не выдумывает.** Нет цены — он так и пишет. Нет замера FPS — он так и пишет.
Нет характеристики — совместимость получает статус ⚪ «недостаточно данных», а не «всё хорошо».

## Что реализовано

| Раздел | Что делает |
|--------|-----------|
| 🖥 Собрать ПК | Анкета с индикатором шагов (бюджет → задача → игры → разрешение → приоритет → CPU/GPU → новые/б/у) **или** запрос одной фразой. Подбор из каталога, 3 варианта (рекомендуемая / дешевле / мощнее), причина выбора каждой детали, итоговая цена |
| ⚙️ Проверить совместимость | 🟢🟡🔴⚪ по сокету, чипсету/BIOS, типу и объёму RAM, форм-фактору, длине видеокарты, высоте/креплению/мощности кулера, мощности БП и разъёмам, M.2/SATA, PCIe |
| 🔧 Улучшить мой ПК | Текущие детали → бюджет → цель → «бюджетный / оптимальный / максимальный» апгрейд с причинами, эффектом, стоимостью и ограничениями |
| 🎮 FPS в играх | Только реальные замеры из базы с источником, настройками, версией и датой. Разные условия не смешиваются |
| 💰 Сравнить цены | Предложения магазинов (цена, наличие, дата, ссылка), лучшая цена, статус источников |
| 📦 Мои сборки | Сохранение, переименование, замена деталей, удаление, сравнение двух сборок, ссылка для друзей; у каждой уникальный ID |
| 👤 Профиль | Telegram ID, дата регистрации, число сборок, история подборов, уведомления, **удаление всех данных** |
| 🛠 Админ-панель | Только `ADMIN_IDS`: статистика, ошибки, импорт каталога/цен/замеров, шаблоны CSV, обновление из фида, рассылка |

Дополнительно: защита от спама, FSM-сценарии с кнопками «Назад» и «Главное меню», глобальный обработчик ошибок,
логирование в файл, валидация ввода, токен только в `.env`.

## ⚠️ Честно о данных и интеграциях

1. **Цен в проекте нет.** Каталог содержит только технические характеристики. Цены попадают в бота
   только из разрешённых источников: CSV, который загружает администратор, или JSON-фид (`PRICE_FEED_URL`).
   **Пока цены не загружены, подбор ПК отвечает «нет данных»** — это не ошибка.
   Цены старше 7 дней считаются устаревшими и в подборе не используются.
2. **Магазины DNS, Ситилинк, Ozon, Wildberries помечены «не подключён».** У них нет официального API цен для покупателей,
   а парсить сайты без разрешения мы не будем. Интерфейс интеграции готов (`bot/integrations/`) — как только у вас
   появится официальный доступ или партнёрский фид, реализуйте метод `fetch()`.
3. **База замеров FPS изначально пуста.** Загрузите реальные замеры (CSV в админ-панели) — каждая строка обязана иметь источник.
4. **Стартовый каталог (80 деталей) внесён вручную по паспортным данным производителей.**
   Перед использованием в продакшене сверьте характеристики с сайтами производителей и при необходимости поправьте через импорт JSON.
   Поля `gaming` / `multi` / `compute` — это *редакторский класс производительности 0–10* для алгоритма подбора, а не FPS и не бенчмарк.
   Длина и разъёмы видеокарт зависят от модели партнёра, поэтому для чипов бот честно ставит 🟡
   «сверьте длину конкретной модели»; чтобы получить точную проверку, добавьте в каталог конкретные модели (с `length_mm`).
5. **Анализ по фото (CPU-Z / GPU-Z) недоступен:** для распознавания нужен внешний OCR/vision-сервис, он не подключён.
   Бот прямо сообщает об этом и предлагает выбрать детали вручную.
6. **«Собрать ПК одной фразой» работает по правилам, без внешнего ИИ.** Бюджет, игры, разрешение, производители, RAM и цель FPS
   разбираются регулярными выражениями; то, что бот не умеет учитывать (например, цвет корпуса), он показывает в разделе «Не учитываю».
   Цель по FPS бот не обещает — он сверяет её с базой замеров. Для подключения LLM замените `parse_phrase` в `bot/utils/parsing.py`:
   подбор всё равно выполняется по проверяемому каталогу.

## Установка

Нужен **Python 3.12+**.

```bash
cd pc_builder
python -m venv .venv

# активация окружения
#   Windows (PowerShell):  .venv\Scripts\Activate.ps1
#   Windows (cmd):         .venv\Scripts\activate.bat
#   macOS / Linux:         source .venv/bin/activate

pip install -r requirements.txt
```

## Настройка

1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируйте токен.
2. Скопируйте `.env.example` в `.env` (`copy .env.example .env` на Windows, `cp .env.example .env` на macOS/Linux).
3. Заполните:
   - `BOT_TOKEN` — токен от BotFather;
   - `ADMIN_IDS` — ваш Telegram ID ([@userinfobot](https://t.me/userinfobot)), несколько — через запятую.

Файл `.env` исключён из git. Никогда не публикуйте токен.

## Запуск в VS Code

1. **File → Open Folder…** → папка `pc_builder`.
2. Установите расширения **Python** и **Pylance**.
3. `Ctrl+Shift+P` → **Python: Select Interpreter** → выберите `.venv`.
4. Откройте терминал (`` Ctrl+` ``) и выполните `python main.py`.
   Появится строка `Бот запущен: @имя_бота` — откройте бота в Telegram и отправьте `/start`.
5. Остановка — `Ctrl+C`.

Отладка: **Run and Debug → Python File → main.py**. Тесты: `python -m pytest -q` или панель *Testing* (значок колбы → *Configure Python Tests → pytest*).

## Первый запуск: как «оживить» подбор

1. Отправьте боту `/admin` (вы должны быть в `ADMIN_IDS`).
2. **💰 Цены → 📄 Скачать шаблон CSV** — файл со всеми деталями каталога.
3. В колонках `shop` и `price` укажите **реальные** магазины и цены (хотя бы одно предложение на детали каждой категории; чем больше — тем богаче подбор).
   `in_stock`: 1 или 0, `url` — ссылка на товар (необязательно).
4. **📥 Загрузить CSV цен** — отправьте заполненный файл. Бот покажет, сколько строк принято и какие отклонены (и почему).
5. Готово: «🖥 Собрать ПК» теперь подбирает сборки. Цены обновляйте не реже раза в неделю.

### Автоматическая загрузка цен из фида (необязательно)

Укажите в `.env`: `PRICE_FEED_URL` (https), при необходимости `PRICE_FEED_TOKEN` (Bearer) и `PRICE_REFRESH_HOURS`.
Формат фида:

```json
[{"category": "gpu", "name": "NVIDIA GeForce RTX 5060 8GB", "shop": "Магазин", "price": 34999, "in_stock": true, "url": "https://..."}]
```

`name` должен точно совпадать с названием в каталоге; неизвестные позиции пропускаются и считаются в отчёте.
Бот обновляет цены по расписанию (APScheduler) и по кнопке «🔄 Обновить из фида».

### Замеры FPS

**🎮 Бенчмарки FPS → 📄 Шаблон CSV.** Колонки: `cpu;gpu;game;resolution;preset;avg_fps;low1_fps;ram;game_version;test_date;source_name;source_url;notes`.
`cpu`/`gpu` — точные названия из каталога, `source_name` обязателен, `resolution` — 1080p / 1440p / 4K, дата — `ГГГГ-ММ-ДД`.

### Расширение каталога

**🧩 Каталог → 📥 Импорт каталога (JSON)** (пример — кнопка «Пример JSON»). Новые детали добавляются, существующие обновляются.
Отсутствующая характеристика = поле не указано (бот поставит ⚪, а не угадает).

## Как работает подбор

1. Из каталога берутся детали с **свежей ценой и наличием** (б/у — только с вашего разрешения).
2. Перебираются пары «процессор + видеокарта»; под каждую подбирается платформа (плата, память, SSD, корпус, кулер) и блок питания с запасом ≥ 25%.
3. Каждая конфигурация проходит `check_compatibility`; в результат попадают только сборки без 🔴 и ⚪.
4. Отсекается всё дороже бюджета. Если ничего не влезает — бот называет минимально возможную цену и **не выходит за бюджет без вашего решения**.
5. Оценка: производительность (с учётом игр и разрешения; узкое звено тянет итог вниз), цена, запас на апгрейд (сокет, слоты, БП), тишина, энергопотребление, доступность. Веса зависят от выбранного приоритета.
6. Показываются до трёх вариантов: рекомендуемый, дешевле (≥ 80% производительности), мощнее.

## Структура проекта

```
pc_builder/
├── main.py                  # точка входа (БД, сидирование каталога, планировщик, polling)
├── config.py                # настройки из .env с валидацией
├── requirements.txt · .env.example · pytest.ini
├── bot/
│   ├── app.py               # Dispatcher: middleware и роутеры
│   ├── handlers/            # start, build, builds, compat, upgrade, fps, prices, profile, admin, picker, misc, errors
│   ├── keyboards/           # inline-клавиатуры
│   ├── middlewares/         # сессия БД, регистрация, антиспам
│   ├── models/              # SQLAlchemy: users, catalog, builds
│   ├── database/            # подключение (SQLite → PostgreSQL сменой URL)
│   ├── services/            # compatibility, builder, upgrade, catalog, build_service, fps_service,
│   │                        # importers, price_updater, stats_service, seed_data
│   ├── integrations/        # интерфейс источников цен: JSON-фид и магазины (помечены «не подключён»)
│   └── utils/               # тексты, рендер, парсинг ввода, логирование
├── tests/                   # 139 автотестов
├── data/                    # SQLite (создаётся автоматически)
└── logs/                    # bot.log (создаётся автоматически)
```

Бизнес-логика (`compatibility`, `builder`, `upgrade`) — чистые функции без БД и Telegram, поэтому легко тестируется и переиспользуется.

## База данных и PostgreSQL

SQLite по умолчанию (`data/pc_builder.db`), таблицы создаются автоматически. Для PostgreSQL:
`pip install asyncpg` и `DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/pc_builder`.
При дальнейшем развитии схемы рекомендуется подключить Alembic (сейчас используется `create_all`).
FSM-состояния хранятся в памяти: после перезапуска активные анкеты сбрасываются (для продакшена можно подключить Redis-хранилище aiogram).

## Тесты

```bash
python -m pytest -q
```

Покрыто: конфигурация, антиспам, все проверки совместимости, алгоритм подбора (бюджет, предпочтения, б/у, устаревшие цены, большие каталоги),
апгрейд, импорт каталога/цен/замеров, интеграции (включая настоящий HTTP-фид на локальном сервере), FPS без смешивания условий,
сохранение/шеринг/права доступа к сборкам, а также сквозные сценарии через настоящий Dispatcher: анкета → сборка → сохранение → ссылка другу, админ-доступ, импорт файлов, рассылка.
Цены в тестах синтетические и существуют только в тестах.

## Безопасность

- Токен только в `.env`; не попадает в `repr`, логи и исходники.
- Админ-функции проверяются по `ADMIN_IDS` на каждом апдейте.
- Чужие сборки недоступны по прямым callback'ам; по ссылке видны только сборки, которыми владелец поделился (можно закрыть).
- Пользовательский текст экранируется в HTML; ссылки в импорте — только http(s); размер файлов — до 2 МБ.
- Удаление данных в профиле стирает пользователя, сборки, историю и события.

## Типичные проблемы

| Симптом | Решение |
|---------|---------|
| `Не задан BOT_TOKEN` | Создайте `.env` из `.env.example` и вставьте токен |
| `Telegram отклонил токен` | Токен отозван или неверен — получите новый у @BotFather |
| `Нет связи с Telegram` | Проверьте интернет, VPN/прокси и доступ к api.telegram.org |
| «Не могу подобрать сборку: нет цен» | Загрузите цены (см. «Первый запуск») |
| «Нет данных» в FPS | Загрузите реальные замеры в админ-панели |
| Нужной детали нет в списке | Добавьте её через импорт каталога (JSON) |
| `ModuleNotFoundError` | Активируйте `.venv` и выполните `pip install -r requirements.txt` |
